# Database Schema Reference (for data population)

Generated from `packages/database/prisma/schema.prisma`. This reflects the
**currently implemented** schema (the Phase 1 subset). For the full,
all-phases conceptual design see [`docs/DATABASE_SCHEMA.md`](../../docs/DATABASE_SCHEMA.md).

## Conventions (from AGENTS.md)

Every table includes:

- `id` — `String`, primary key, `@default(cuid())`
- `createdAt` — `DateTime`, `@default(now())`
- `updatedAt` — `DateTime`, `@updatedAt`

Never hard-delete production data. `injury_reports` and `lineup_reports` are
append-only: each update is a **new row**, never an overwrite. "Current"
status is derived by querying the latest `reportedAt` per player.

Column notes below: **required** = must be supplied on insert; **optional** =
nullable (`?`); **default** = auto-filled if omitted; **auto** = generated by
Prisma.

## prop_lines

A prop market for a player: consensus line, both sides' American odds, and a
mock projection. The per-game series the UI charts is derived at request time
from `player_game_stats`, not stored here.

| Column     | Type        | Required | Notes                                        |
| ---------- | ----------- | -------- | -------------------------------------------- |
| id         | String      | auto     | cuid PK                                      |
| statType   | StatType    | required | enum (see below)                             |
| line       | Float       | required | use `.5` values so a game is never a push    |
| overOdds   | Int         | required | American odds (e.g. -110)                    |
| underOdds  | Int         | required | American odds                                |
| projection | Float       | required | placeholder until the projection engine lands |
| playerId   | String (FK) | required | → players.id                                 |
| createdAt  | DateTime    | default  | now()                                        |
| updatedAt  | DateTime    | auto     |                                              |

Constraints: **unique** `(playerId, statType)`. Indexed on `playerId`.

## Insert order (respecting foreign keys)

1. `users` — standalone
2. `teams` — standalone
3. `seasons` — standalone
4. `players` — needs `teamId`
5. `games` — needs `seasonId`, `homeTeamId`, `awayTeamId`
6. `player_game_stats` — needs `playerId`, `gameId`
7. `prop_lines` — needs `playerId`
8. `injury_reports` — needs `playerId`
9. `lineup_reports` — needs `playerId`
