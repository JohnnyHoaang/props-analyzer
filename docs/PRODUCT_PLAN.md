# Product Vision

The application provides detailed NBA player performance analysis.

Users choose:

* Game
* Player
* Statistical category
* Target value

The application returns:

* Projection
* Expected range
* Historical performance
* Matchup analysis
* Positive factors
* Risk factors
* Projection explanation

The product is presented as an analytics and educational tool, not as a
guarantee of future results. Avoid guarantee language ("guaranteed", "lock",
"can't miss", "sure win", "risk-free"). Prefer evidence-level language
("higher evidence", "moderate evidence", "limited evidence", "insufficient
information").

---

## Supported Categories

* Points
* Rebounds
* Assists
* Three Pointers Made
* Steals
* Blocks
* Turnovers
* Points + Rebounds
* Points + Assists
* Rebounds + Assists
* Points + Rebounds + Assists

## Explicitly Out of Scope

* Subscription / paid tiers (dropped from the plan; see `AGENTS.md`)
* Live in-game predictions
* Complex parlays or combination analysis
* Referee analysis
* Travel-distance modeling
* Large language model explanations
* Deep neural networks
